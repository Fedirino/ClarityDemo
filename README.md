# Clarity Demo

A live demo of [Clarity](https://github.com/Fedirino/Clarity) — the pool test strip analyzer. Try it without signing in or setting up an API key.

## What's different from the full app

- **No Firebase auth** — drops straight into the app
- **Pre-loaded sample data** — dashboard, history, trends, and insights all working with realistic pool readings
- **Mocked AI responses** — upload a test strip photo and get sample readings back. Chat works too with demo answers
- **Demo badge** — clearly marked so you know it's not the real deal
